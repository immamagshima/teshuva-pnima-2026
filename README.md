# תשובה פנימה

מרחב הקשבה משותף לקראת יום כיפור, עם קרן בן עמי ואמא מגשימה.

אתר סטטי לשיתוף מסך בזום: הקשבה, תשובה, סליחה ומחילה, טיימרים, משחקי מילים ואיסוף שורות שנמסרו לשיר קהילתי.

## שימוש

פותחים את האתר ומשתפים מסך. כלים מאפשרים ניווט במפגש, איסוף שורות מהצ׳אט ובחירת קובץ שמע. ההפקה המוזיקלית נעשית בנפרד.

שורות שנאספות נשמרות רק בדפדפן במכשיר שבו נאספו. אין סנכרון בין מכשירים או חיבור אוטומטי לזום. קובצי שמע מקומיים אינם מועלים לאתר. המאגר אינו מכיל שורות משתתפות או הקלטות אישיות.
